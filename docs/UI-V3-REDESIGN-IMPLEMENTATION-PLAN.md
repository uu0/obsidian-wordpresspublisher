# UI V3 重构实施计划

> 基于方案A：从 dev 分支重构
> 创建日期：2026-03-14
> 分支：feature/ui-v3-redesign

---

## 📋 总体目标

基于 dev 分支（包含最新的安全性和稳定性功能），实现 UI-CODE-REVIEW-V3 的设计要求，同时合并 feature/ui-refactor 的改进。

---

## 🎯 核心原则

1. **保留 dev 分支的核心功能**
   - ✅ API Key AES-256-GCM 加密
   - ✅ 远程图片加载超时和重试
   - ✅ 图片加载状态提示
   - ✅ 所有 bug 修复

2. **合并 feature/ui-refactor 的改进**
   - ✅ CSS 变量标签颜色（支持主题切换）
   - ✅ Sticky 滚动监听（滚动阴影效果）
   - ✅ 自定义 Prompt 支持
   - ✅ AI 功能整合

3. **实现 UI-CODE-REVIEW-V3 的设计要求**
   - ✅ 预览优先布局
   - ✅ 四段式预览区
   - ✅ 浮动面板系统
   - ✅ 编辑交互
   - ✅ 响应式布局

### Phase 2: 实现预览优先布局 ⏳

**目标**：实现主区域=预览，设置/历史=浮动面板的布局

**设计要求**（来自 UI-CODE-REVIEW-V3）：
```
┌─────────────────────────────────────────────────────────┐
│                     Modal Header                         │
├──────────────────────────────┬──────────────────────────┤
│                              │  ┌────────────────────┐  │
│                              │  │  Settings Panel    │  │
│      Preview Area            │  │  (Collapsible)     │  │
│      (Main Content)          │  └────────────────────┘  │
│                              │  ┌────────────────────┐  │
│                              │  │  History Panel     │  │
│                              │  │  (Collapsible)     │  │
│                              │  └────────────────────┘  │
└──────────────────────────────┴──────────────────────────┘
```

**任务清单**：
- [ ] 2.1 创建新的布局容器结构
  - `wp-layout-container` (flex 容器)
  - `wp-layout-preview` (预览区，flex: 1)
  - `wp-layout-panels` (面板区，固定宽度 320px)
- [ ] 2.2 实现 CSS 布局样式
  - 桌面端：两列布局（预览 + 面板）
  - 移动端：单列布局（预览在上，面板在下）
- [ ] 2.3 移除旧的标签页系统
  - 删除 `renderTabBar`
  - 删除 `currentTab` 状态
- [ ] 2.4 测试布局响应式

**预计时间**：2-3 天

### Phase 3: 实现四段式预览区 ⏳

**目标**：实现特色图片、摘要、标签、文章预览的四段式布局

**设计要求**（来自 UI-CODE-REVIEW-V3）：
```
┌─────────────────────────────┐
│  1. Featured Image Section  │  ← 特色图片（带编辑图标）
├─────────────────────────────┤
│  2. Excerpt Section         │  ← 摘要（带编辑图标）
├─────────────────────────────┤
│  3. Tags Section            │  ← 标签（带编辑图标）
├─────────────────────────────┤
│  4. Article Preview         │  ← 文章预览（浮动，带编辑图标）
│     (Sticky)                │
└─────────────────────────────┘
```

**任务清单**：
- [ ] 3.1 实现特色图片预览区

  - 添加 ✍️ 编辑图标
  - 点击编辑打开图片选择器
- [ ] 3.2 实现摘要预览区
  - 显示摘要内容
  - 添加 ✍️ 编辑图标
  - 点击编辑进入内联编辑模式
- [ ] 3.3 实现标签预览区

  - 添加 ✍️ 编辑图标
  - 点击编辑进入内联编辑模式
- [ ] 3.4 实现文章预览区

  - 实现 Sticky 浮动效果
  - 添加 ✍️ 编辑图标
  - 点击编辑打开模态框编辑
