## 需求总结

### 1. Frontmatter 检测修复

- 如果本地值或远端值为空，直接使用不为空的数值

### 2. 桌面端 UI 重构

**布局结构：**

- 双栏布局，比例 2:1（左侧预览：右侧设置）
- 左侧：预览区域（参考 dev 分支的预览标签页）
- 右侧：基本设置 + 历史记录

**左侧预览区域：**

1. **特色图片**
   - 有图片：显示图片预览
   - 无图片：显示特色图片设置 UI
   - 点击 ✏️：显示特色图片设置 UI
2. **摘要**
   - 按 dev 分支显示方式
   - ✏️ 按钮：编辑摘要
   - 🤖 按钮：AI 生成摘要
3. **标签**
   - 按 dev 分支显示方式（彩色标签）
   - ✏️ 按钮：编辑标签
   - 🤖 按钮：AI 生成标签
4. **文章预览**
   - 默认：HTML 渲染预览
   - 点击 ✏️：切换到 Markdown 源码编辑模式
   - 编辑模式显示 ✅ 按钮：保存并返回预览模式

**右侧设置区域：**

1. **基本设置**（简化版）

   ```
   标题 ❕
   [文本输入框]
   
   Slug ❕
   [文本输入框]
   
   状态 ❕      [下拉选择框]
   评论 ❕      [下拉选择框]
   发布格式 ❕   [下拉选择框]
   发布为新文章 ❕ [开关]
   ```

   - ❕ 按钮：点击或悬停显示该选项的说明

2. **历史记录**

   - 显示发布历史

**移除的内容：**

- 特色图片设置 UI（移到左侧预览区）
- AI 摘要生成 UI（移到左侧预览区）
- AI 标签生成 UI（移到左侧预览区）
